# Student Performance Analytics System

## Project Overview
This project analyzes student performance data using Python and Pandas.

## Features
- Topper Analysis
- Average Marks Calculation
- Failed Students Detection
- Students With Zero Failures
- High Absence Analysis
- Gender-wise Average Marks
- Search Student By Age

## Technologies Used
- Python
- Pandas
- CSV Dataset
- Git & GitHub
